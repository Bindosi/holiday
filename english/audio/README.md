# Lesson recordings

Dialogue audio for the WhatsApp English lessons. The bot sends these by link, so they must be here, on GitHub Pages, with exactly these file names.

How to record:

- Two people who speak English clearly; read slowly and naturally, about 20 seconds per dialogue.
- Record on a phone in a quiet room, then save as **MP3** (or M4A/OGG). Keep each file under 1 MB.
- Upload the files to this folder, then set `ENGLISH_AUDIO=true` on the server and open `/optimize-clean`.

Until then the bot shows the dialogue as text, so nothing breaks.
